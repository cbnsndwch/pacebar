PaceBar is an independent, open-source menu-bar app for tracking AI coding
subscription usage. It's maintained by
[@cbnsndwch](https://github.com/cbnsndwch) and is community-driven — issues,
pull requests, and new provider plugins are all welcome.

## Origins & attribution

PaceBar is a fork of [OpenUsage](https://github.com/robinebers/openusage) by
Robin Ebers. It is **not endorsed by or affiliated with** the upstream project.
The original copyright and attribution are retained in the project's
[`NOTICE.md`](https://github.com/cbnsndwch/pacebar/blob/main/NOTICE.md).

The fork added a plugin-based provider system, a local HTTP API, proxy support,
multi-profile tracking, tray progress bars, and an opt-in leaderboard, among
other changes — see [Fork branding](/docs/contributing/fork-branding) for the
rebrand details.

Inspired by [CodexBar](https://github.com/steipete/CodexBar) by
[@steipete](https://github.com/steipete) — same idea, a very different approach.

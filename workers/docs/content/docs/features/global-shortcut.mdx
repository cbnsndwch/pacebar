---
title: Global shortcut
description: Toggle the PaceBar panel from anywhere with a customizable global keyboard shortcut.
---

PaceBar can register a system-wide keyboard shortcut that toggles the panel from
any app.

## Set a shortcut

Open **Settings → System** and set your shortcut. It uses the standard accelerator
format, for example:

```
CommandOrControl+Shift+U
```

`CommandOrControl` maps to ⌘ on macOS and Ctrl on Windows, so one binding works
on both platforms.

## Disable it

Clear the shortcut to disable the global toggle. PaceBar still opens from the
tray icon.

## Notes

- The shortcut is stored in your settings and restored on launch.
- If another app already owns the same combination, pick a different one.

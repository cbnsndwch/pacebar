title: Quick start
description: Enable the providers you use, arrange your panel, and pick a refresh interval.
---

PaceBar reads usage from AI coding subscriptions you're already signed in to.
Most providers need no configuration — PaceBar finds the existing credentials on
your machine.

## 1. Open the panel

Click the menu-bar / tray icon, or use the
[global shortcut](/docs/features/global-shortcut) once you've set one.

## 2. Enable providers

Open **Settings** and toggle on the providers you use. Each provider is a
[plugin](/docs/plugins); see [Providers](/docs/providers) for the full list and
what each one tracks. Disabled providers stay hidden from the panel and the
[local HTTP API](/docs/features/local-http-api).

Some providers need a one-time step (for example, a self-hosted endpoint or a
token). Those are called out on each provider's page.

## 3. Arrange your panel

Drag providers to reorder them. The order you choose is the order they appear in
the panel, in the tray bars, and in the local HTTP API responses.

Mark up to four providers' primary progress bars to show directly in the
[tray icon](/docs/features/tray) for at-a-glance usage.

## 4. Pick a refresh interval

PaceBar refreshes on app load and on a timer you choose (5 / 15 / 30 / 60
minutes). You can also refresh manually at any time.

## Next steps

- Set a [global shortcut](/docs/features/global-shortcut) to toggle the panel.
- Track [multiple Claude profiles](/docs/features/multi-profile) separately.
- Let other local apps read your data via the
  [local HTTP API](/docs/features/local-http-api).
- Route requests through a [proxy](/docs/features/proxy) if you need to.

---
title: Providers
description: Every AI coding subscription PaceBar supports and what each one tracks.
---

Each provider is a [plugin](/docs/plugins). Enable the ones you use in Settings;
most need no configuration because PaceBar reads credentials already on your
machine. Providers that need a one-time setup step say so on their page.

| Provider | Tracks |
| --- | --- |
| [Amp](/docs/providers/amp) | Free tier, bonus, credits |
| [Antigravity](/docs/providers/antigravity) | Usage across all models |
| [Claude Code](/docs/providers/claude) | Session, weekly, extra usage, local tokens; multi-profile |
| [Cloudflare AI](/docs/providers/cloudflare-ai) | Self-hosted gateway metering, spend, daily burn |
| [Codex](/docs/providers/codex) | Session, weekly, reviews, credits |
| [Copilot](/docs/providers/copilot) | Premium, chat, completions |
| [Cursor](/docs/providers/cursor) | Credits, total/auto/API usage, on-demand |
| [Factory / Droid](/docs/providers/factory) | Standard, premium tokens |
| [Gemini](/docs/providers/gemini) | Pro, flash, workspace/free/paid tier |
| [JetBrains AI](/docs/providers/jetbrains-ai-assistant) | Quota, remaining |
| [Kimi Code](/docs/providers/kimi) | Session, weekly |
| [Kiro](/docs/providers/kiro) | Credits, bonus credits, overages |
| [MiniMax](/docs/providers/minimax) | Coding plan session |
| [OpenCode Go](/docs/providers/opencode-go) | 5h, weekly, monthly spend limits |
| [Perplexity](/docs/providers/perplexity) | Local cache-based auth |
| [Synthetic](/docs/providers/synthetic) | Usage tracking |
| [Windsurf](/docs/providers/windsurf) | Prompt credits, flex credits |
| [Z.ai](/docs/providers/zai) | Session, weekly, web searches |

Want a provider that isn't listed?
[Open an issue](https://github.com/cbnsndwch/pacebar/issues/new) or
[write a plugin](/docs/plugins/authoring).
